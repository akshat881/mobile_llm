Here is a simple and efficient way to do that using the lambda function within Python's built-in sorted() method.

python 
data = [
    {'name': 'Alice', 'age': 25},
    {'name': 'Bob', 'age': 20},
    {'name': 'Charlie', 'age': 30}
]

# Sort by 'age'
sorted_list = sorted(data, key=lambda x: x['age'])

print(sorted_list)

This will output the list of dictionaries ordered by the 'age' value in ascending order.
